## Why

`talea` 默认 TUI 的会话列表已经接收终端窗口尺寸，但问题文本仍固定截断为最多 100 个字符，宽屏时可读内容没有利用可用空间。详情页的部分汇总表也使用固定列宽，窗口变化后存在同类布局不一致。

## What Changes

- 保留会话列表元数据行的固定列宽与字段对齐。
- 让列表中的首次提问和最近消息按当前终端可用宽度动态截断，宽屏展示更多文本，窄屏避免横向溢出。
- 窗口缩放时重新渲染列表问题文本，保持选择、过滤和恢复行为不变。
- 让详情页的模型汇总、用户轮次和子 Agent 行按窗口宽度适配；现有图表宽度逻辑保持不变。
- 增加宽屏、窄屏、中文显示宽度和窗口缩放的回归测试。

## Capabilities

### New Capabilities

- `tui-responsive-layout`: TUI 列表问题文本和详情固定表格根据终端窗口宽度安全适配。

### Modified Capabilities

无。

## Impact

- 影响 `internal/tui` 的列表项渲染、窗口尺寸处理、详情页表格渲染及测试。
- 不改变索引、数据库、Agent 原始会话文件、恢复命令或 CLI `talea list` 输出。
- 不新增依赖，不引入网络或持久化变更。
